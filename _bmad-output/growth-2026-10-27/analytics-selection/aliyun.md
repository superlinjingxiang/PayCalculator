# 阿里云现成统计方案：选择意见

**阿里云确实已有现成能力，首选候选是 SLS 的 Nginx 访问日志仪表盘。** 它已有 PV/UV、来源页和热门 URL 报表，不必继续自制一套离线分析界面。ARMS 用户体验监控（RUM）则适合后续需要浏览器用户标识、会话、性能和异常时使用。两者都是需开通并承担按量费用的云服务；本轮未登录账号、未开通、未购买。[1][2][3]

结论是**当前适用性推荐**，不是已接入结果。公开文档只来自同一供应商，未获得独立验证；以下供应商声明均为中等置信度，实际账号资格、可用额度及控制台条款仍未知。

## 条件与选择

需求来自任务：已有上海 ECS + 独立 Nginx，通过 HTTP/IP 预览；无域名/HTTPS/备案；工资在本地计算；需要浏览量、访客、来源及页面报表。这些是需求条件，不是证明供应商兼容性的证据。

| 候选 | 现成程度及口径 | 当前站点接入判断 | 选择 |
| --- | --- | --- | --- |
| SLS Nginx 访问日志分析 | 接入向导自动创建索引和仪表盘；来源页、热门地址、PV/UV现成。示例 PV 是日志条数，UV 是客户端 IP 近似去重。[1] | 官方前提是机器组、采集器网络和持续新增的 Nginx 日志；未列站点域名/HTTPS要求。因此 HTTP/IP 的日志采集路线可行是有文档支持的工程推断，仍需实际验证。[4] | **当前首选**，但报表必须明确“请求量/独立 IP”，并过滤静态资源、探测及机器人，才能更接近页面浏览。 |
| ARMS RUM Web & H5 | SDK 页面访问去重作为 PV，SDK 用户 ID 去重作为 UV，有会话与性能指标；日志也有 URL、referrer。[5][6] | 支持 HTML 内嵌 JS 或 npm；应用创建只列名称、描述，生成 endpoint。文档未明确保证裸 IP+HTTP，也未列域名验证；不能把“没写限制”当作已通过。[2] | 需要真实浏览器访问、会话体验分析时的备选；只看访问报表会引入更广采集。 |

这两项是**阿里云托管可观测服务中的现成功能，不是可自行部署的开源站长统计产品**：官方交付路径是控制台开通、创建资源、采集并计费。这里未对每个 SDK/采集器源码许可证做审计，不能把组件可能开源等同于整个报表服务开源。[2][3][7]

## 开通与费用

**SLS：** 必须先开通日志服务。官方资源管理文档说明开通时会自动创建 `AliyunServiceRoleForSLSAudit` 角色；另有官方产品的 SLS 开通流程明确要求勾选日志服务协议。该流程可证明开通存在服务条款，但当前账号会显示哪版协议、本轮未确认。[7][8]

按使用功能计费为先使用后付费、按天结算；月免费额度包括日志存储 500 MB、日志索引流量 500 MB、读写流量 500 MB、读写次数 100 万、活跃 Shard 31 个天；月底清零，超额收费。[3] 额度为账号共享；新建 LogStore 默认是按写入数据量计费，不能直接套用上述额度。[9] **没有已核实的本项目月费数字**：官方价格链接本轮返回读取错误，尚需确认上海各项超额单价、已有账号用量及日志规模。SLS费用不能仅用PV计算。[3][9]

**RUM：** 官方当前中国公有云价格为 **0.15 元/OCU**，会话免费额度 **80 OCU/月**，自定义上报 **20 OCU/月**；开通计费版本才享额度。Web&H5 **200 计费会话 = 1 OCU**，因此推算会话额度约 **16,000 次/月**，超额每万计费会话约 **7.50 元**，不是每万 PV。额度跨应用/实例共享，回放、自定义事件等另有计费；默认优先会话计费，30天明细、90天指标为默认存储权益。此推算不含其他收费项，也不证明账号剩余免费额度。[10]

无论选择哪项，本轮都不能承诺“永久免费”“免费额度用完自动停”。RUM 的新购/开通流程具体协议和是否需要充值，公开证据不足；不能用旧版前端监控免费试用协议推断新版 RUM。[10]

## 建议落实方式与边界

建议主任务将 **SLS Nginx 预置仪表盘列入首选接入方案**：先核对服务是否已开通、账号余量、计费模式及上海报价，再以专用日志和最短必要留存接入，验证已知访问对应的页面量、独立IP、来源及热门页。它复用已有 Nginx，不增加浏览器 SDK。接入不能仅停在写文档；若激活付费服务尚未授权，则先完成可审阅配置和验收步骤，再处理开通决定。

若用户的“访客”明确指浏览器访客及会话，而不是独立IP，优先与成熟开源站长统计一起比较，RUM可作为阿里云备选。反对SLS首选的最强理由是：其默认报表按服务器请求统计，不能自动等同于人类页面浏览，客户端路由与缓存浏览也需另作验证。该限制直接来自官方示例计数口径。[1]

域名、HTTPS、备案应分开判断：**未在采集文档中列作前提，只能支持技术路径判断，不能推导公共站点的合规豁免。** 本轮没有核实法律资质要求，不作“无备案可正式上线”的结论。[2][4]

## 未决问题

1. 当前账号SLS/RUM是否开通、免费额度是否已被其他应用占用，须只读查看账号。
2. SLS上海超额价及实际日志规模，须读取可用报价页面并测量后估算。
3. RUM裸IP+HTTP是否全部功能可用，须在已获开通授权后做小范围实际验证。
4. 来源数据的完整性及工资隐私：选型时不能默认采集完整查询串、工资输入或回放；实际字段清单和脱敏方案尚需实施确认。
