# PayTools 独立评审：增长与上线能力

评审日期：2026-10-27。范围：现有完整代码与部署说明，聚焦 SEO、国内广告联盟、真实浏览量、隐私及计算可信度。此报告为实现前基线，不代表已审核后续新增实现。

方法：BMAD Review 的 adversarial、edge-case-hunter、verification-gap 三个视角；受当前并发槽限制，由本独立评审 agent 顺序执行。代码位置按本次读取版本。仅写本报告，未修改产品代码、未操作用户浏览器。

已阅读本地 Next.js 16.4 文档：`node_modules/next/dist/docs/01-app/02-guides/static-exports.md`、`01-app/03-api-reference/04-functions/generate-metadata.md`。静态导出不能靠动态 Next Route Handler 收集线上 PV；需要独立采集服务、托管日志或第三方统计。

## 决策结论

现有计算内核、政策分期、Decimal 精度及本地 CSV 架构可以继续使用。测试 agent 提供的基线为 lint、typecheck、96 个 Vitest、10 个默认 E2E 及 2 个额外广告配置 E2E 全通过，详见同目录 `testing.md`。这些结果证明当前已实现行为可回归，不能证明广告已投放、站点已可索引或已拥有真实访问量。

本次发现分为实现缺口、可复现缺陷和上线依赖；后者不能描述成已完成接入。当前最需要修复的是外省沿用上海费率及广告选择存储失败路径。

## Edge-case hunter：路径结论

- **同意存储失败**：调用链 `saveAdConsent → CustomEvent → useSyncExternalStore → getSnapshot` 缺少事件到内存状态的接线；对应 A6。
- **上海切至未核实城市**：`changeProvince/changeCity` 保留所有费率，`validateForm` 只要求非空，`handleSubmit` 随即提交；对应 A4。
- **错误广告供应商**：任意非空字符串绕过渲染门禁，没有适配器选择/拒绝分支；对应 A7。
- **真实 origin 已设置而预览配置仍在**：前端可输出可索引元数据，服务器仍返回 noindex；对应 A3，属于正式发布验收依赖。

以下已有处理，不作为缺陷：金额输入上界与非负校验；上海公积金5/6/7档限制；上海上下半年边界；手动地区不套上海上下限；改参清除旧结果；仅算个税的余额警告；拒绝广告后可继续计算。

## 后续最终评审接收条件

1. 提供本次新增/修改文件清单与最终测试结果，区别既有修改和增长实现。
2. SEO 验证至少覆盖静态 HTML、真实 origin 构建、服务器 noindex 状态，不用未经验证的搜索量/竞争度数字。
