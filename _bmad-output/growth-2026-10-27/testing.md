1. **真实广告投放未接通。** 当前 `AdSlot` 仅生成 `data-ad-provider` 和 `data-ad-slot` 容器，没有请求联盟脚本；上述测试不能证明联盟审核、填充、曝光或收益。
2. **没有 PV 采集实现。** 未见统计脚本、事件或统计数据源，因此无法验收真实浏览量。浏览量必须以部署后的真实采集为准，测试访问不得伪造成生产访问量。
3. **生产 SEO 状态未知。** 当前仅有 `.env.example`，没有生产域名配置；默认 robots 会禁止抓取，sitemap 无生产条目。这是安全的开发默认行为，但上线验收必须使用真实 origin。
4. **现有页面检查硬编码 `2026-10-11`。** 本次增加或更新时间应改为验证实际页面的元数据/来源日期，避免日期文字成为脆弱断言。
5. **浏览器测试可能复用端口 3000 上既有服务。** 当前开始时端口空闲，实际由测试拉起静态服务；后续验收应确认相同条件，避免测错开发服务或旧产物。

## 本次实现后的验收矩阵

### SEO 与内容

- Given 真实 HTTPS origin，When 静态构建，Then 新增落地页返回 200、具有唯一 title/description/H1、指向自己的 canonical，并出现在 sitemap 中。
- Given 不存在 origin 或 origin 为占位地址，When 构建，Then 不输出错误 canonical，保持预览不可索引。
- Given 选择某个长尾入口，When 点击计算，Then 能抵达支持该需求的计算界面，内容不声称尚未实现的地方政策/年终奖能力。
- Given 360px 与桌面视口，When 打开新增页面，Then 无横向溢出、主要行动可见、内部链接有效。
- Given 结构化数据，When 序列化，Then 为合法 JSON，内容和页面可见事实一致；不得编造评价或搜索量。

### 广告

- Given provider 或 slot 缺失/无效/关闭，When 页面加载，Then 不加载联盟第三方脚本，也不留下空白广告块。
- Given 有效配置但尚未同意，When 页面加载，Then 不向联盟发起请求。
- Given 明确同意，When 结果页广告位出现，Then 只按平台允许方式加载脚本/广告，不重复注册，无输入数据泄露。
- Given 拒绝或撤回选择，When 页面继续使用，Then 计算功能正常，后续广告请求停止；已加载 SDK 的生命周期限制需如实记录。
- Given 广告被拦截或脚本失败，When 计算和导出，Then 功能无阻断、无未处理异常、不出现诱导点击。

### 浏览量与隐私

- Given 未配置统计 ID 或关闭，When 打开任意路由，Then 不加载统计脚本。
- Given 已配置统计，When 用户按产品约定启用，Then 一次页面访问只记一次 PV；站内导航正确记新路径，避免首屏初始化加手动重复。
- Given 用户输入工资、基数、地区或专项扣除，When 计算或切换路径，Then 统计 payload、URL、日志中不含工资输入、结果、自由文本、查询参数或表单内容。
- Given 第三方统计失败/被拦截，When 用户计算，Then 工具仍正常。
- Given 数据源无记录，When 查看统计说明/管理入口，Then 显示未接入或待采集，不能显示随机数字或把本地存储当作站点总 PV。
- Given 已部署生产站，When 从独立访客浏览器访问数个路径，Then 在统计平台调试与报表中验证 PV，并记录时间窗、域名、路径和延迟；区分人工访问、自动测试与爬虫。
