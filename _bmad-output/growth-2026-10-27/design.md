## 判断与优先级

现有产品的差异点已经存在：全年 12 个月累计预扣、年中入职、不同月份工资、上海 7 月政策切换、本地 CSV、可追溯政策来源。增长设计应把这些能力变成明确入口和可验证的内容，而非再做一个泛「工资计算器」标题。

| 优先级 | 现状与影响 | 本次可执行设计 |
|---|---|---|
| P0 | 首页与工具页均是相近全国工资词，解释页标题仅「计算方法」 | 上海场景优先：新增一个独特上海页，完善既有方法页，全国累计预扣工具词为次级 |
| P0 | 广告已有容器与同意选择，没有具体 SDK | 仅启用经审批的具体平台适配器；页面不把空容器称为广告已接入 |
| P0 | 未有真实访问量统计和查看入口 | 第一方同源白名单PV、无标识Nginx专用日志、本地HTML/JSON站长报告，不承诺UV/真人数 |
| P0 | 说明页称不默认7%或按工资取基数，但表单有这些预设 | 统一为「估算预设，可调整为单位申报值」；结果与说明保持同一口径 |
| P0 | 上海独有规则被放在大段说明中 | 新增上海落地页，首屏就是上海工具，展示上下半年政策差异和来源 |
| P1 | 移动端先读 hero-note 后到工具 | 上海页采用紧凑说明；避免在计算器之前增加广告或长篇文章 |

证据路径：`src/app/page.tsx`、`src/app/salary-calculator/page.tsx`、`src/app/methodology/page.tsx`、`src/components/SalaryCalculator.tsx`、`src/components/SalaryResults.tsx`、`src/components/AdSlot.tsx`、`src/components/AdConsent.tsx`、`src/lib/ads.ts`、`src/app/privacy/page.tsx`、`src/app/globals.css`、`SEO_STRATEGY.md`。这些是项目现状证据，不是外部市场竞争证据。

首页 H1 可以保留「你的工资，到手多少？」；在紧邻副标题中自然出现「2026 累计预扣」「12个月税后工资」。工具页 H1 应明确主推词。每个页面先回答自己的问题，不把所有词拼接到一个标题；无需新增 meta keywords。

本轮只新增一个上海页并完善既有方法页，暂不扩写文章或金额页。上海页复用现有上海可验证计算能力，默认地区明确为上海；包含1—6月和7—12月规则切换说明、缴费基数与工资不同的解释、官方来源和上海专属 FAQ。不得把上海区县当作具有独立费率的城市页。当前IP预览继续noindex，准备SEO代码不等于已获得搜索曝光。

建议上海页 description：输入月薪与个人缴费参数，按2026年上海上下半年社保、公积金规则逐月估算税后工资和累计预扣个税，查看12个月明细及政策依据。

## 广告展示体验

- 继续使用 `result-footer` 和 `content-footer`。结果后广告放在完整结果、明细下载和限制说明之后；不得插入金额卡片、表单字段、CSV按钮之间。
- 容器顶部始终可见「广告」，采用现有低层级白卡，不使用与「计算工资」相同的主操作样式。
- 每个广告位限制在其父容器宽度内，移动端不制造整页水平滚动；只有明细表允许独立横滚。
- 未配置、平台不支持、用户拒绝：不渲染广告。加载中、无填充、失败：不显示假的成功信息；静默结束或显示可理解的轻量说明，不阻断工资计算。
- 已同意后预留与平台规格相符的高度；不得以首次渲染任意120px作为所有广告格式的最终合同。
- 本轮PV采用第一方同源、无标识采集，不接第三方统计SDK；在隐私页据实披露，不复用广告同意作为PV开关。广告拒绝、撤回和存储异常时的本页选择仍须可靠生效。
- 平台脚本具有页面执行能力；文案应精确承诺「本站不主动向广告请求传入工资字段」，不能未经平台审计就保证第三方永远无法访问页面内容。

## 浏览量与站长体验

用户的「看到网页浏览量」优先解释为站长能看到真实流量。[ASSUMPTION] 本次不要求把经营数据公开给所有访客。

采纳第一方同源白名单PV：首屏、客户端导航和刷新各上报一次固定页面路径；仅成功GET计数、no-store，重渲染不重复，静态资源、HEAD及非白名单不计。Nginx专用日志只记录时间和页面，不含IP、UA、referrer、query、工资或标识。原始日志保留30天、轮转并限制权限，日志和报告不进入公开目录。

交付本地可打开的HTML和JSON站长报告。以现有IP预览受控访问核对真实PV，不要求先有域名或第三方统计账号；明确标识「预览环境」、Asia/Shanghai时区、生成时间、采集起点、覆盖区间及首日不完整，不补造历史。广告真实激活仍等待正式域名、适用备案、联盟账号和获批Web代码。

| 查看项 | 展示规则 |
|---|---|
| PV | 标明为页面浏览量；同人多次页面访问可产生多个PV |
| UV/真人数 | 本版不采集唯一标识，不报告UV或承诺真人数 |
| 趋势 | 今日、近7天、近30天；按上海时区、采集覆盖与部分日显示 |
| 页面 | 按规范化路径查看，区分工具页和上海页；不把salary查询值写入地址 |
| 搜索效果 | 当前预览noindex；PV不能代替搜索曝光、查询或排名 |
| 采集限制 | JS禁用、拦截或故障可漏报；自动化与伪造请求可增加PV，不视为真实用户数 |
| 空白/受阻 | 明确「暂无采集数据」或覆盖不足，不以0冒充采集成功 |

静态站不新增公开管理员路由；经现有云助手取回汇总，在本地打开报告。报告兼容轮转且不重复读取，不在前端暴露查询密钥。不使用 `localStorage` 本机刷新次数冒充全站浏览量；本轮不扩展事件转化追踪。

## 验收场景

1. Given 页面静态导出，When 查看HTML，Then 每页有独立可读title/H1、真实有效canonical；无正式域名时保持既有禁止索引策略。
2. Given 上海页已发布，When 打开并计算，Then 默认上海、能解释7月切换且链接到对应官方规则，不承诺全国费率自动核实。
3. Given 用户拒绝广告，When 计算并下载CSV，Then 功能完整且无广告脚本请求。
4. Given 用户允许广告且平台有效，When 广告加载或失败，Then 有明确广告标识，页面不遮挡、不整页溢出、结果仍可使用。
5. Given 预览同源PV已启用，When 首屏/导航/刷新及日志轮转，Then 仅成功GET固定路径各计一次、无缓存，HTML/JSON上海时区报告无重复且显示采集起点/覆盖/部分日；日志不含IP、UA、referrer、金额、query或hash。
6. Given 360px屏幕与键盘操作，When 查看结果、同意选择和页脚入口，Then 操作可见、标签明确、焦点可达，横滚限于表格。
7. Given 第三方请求受阻或断网，When 继续计算，Then 计算不依赖统计或广告服务，无假成功或虚构流量数字。

## 设计交付边界

保留现有视觉体系，未生成新品牌、人物画像或视觉稿。所列检索词已有竞争，属于待验证机会，不含流量、收入或排名承诺。无正式域名、备案和获批联盟账号时保持noindex与广告关闭；广告实际投放仍为后续未完成事项。本轮仅调整设计方案，待用户批准实施。
