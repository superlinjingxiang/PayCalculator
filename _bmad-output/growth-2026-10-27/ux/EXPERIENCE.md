## Foundation

响应式中文Web，Next.js App Router静态导出，自有CSS组件，无新UI库。DESIGN.md是视觉身份参考。工资计算继续在浏览器本地完成。修订2先交付代码与现有IP预览真实PV，保持noindex；尚待用户批准实施。无域名、备案和获批联盟账号，广告真实激活仍待外部材料。

## Information Architecture

| 表面 | 入口 | 目的 |
|---|---|---|
| 首页 `/` | 站点根地址 | 发现价值，立即开始计算 |
| 上海 `/shanghai-salary-calculator/` | 首页内容链接、搜索 | 本轮唯一新增页，优先承接上海税后工资及7月政策切换 |
| 工具 `/salary-calculator/` | 导航、搜索 | 次级承接全国2026累计预扣与12个月明细 |
| 方法 `/methodology/` | 导航、结果来源 | 解释同薪个税变化与年中入职，带回工具 |
| 政策 `/policy-sources/` | 导航、结果来源 | 原始政策、适用月份、核实状态 |
| 隐私 `/privacy/` + PrivacyChoices | 页脚、广告启用时 | 第一方PV披露、广告选择与退出 |
| ReportEntry | 本地HTML/JSON文件 | 站长查看上海时区每日及页面PV、采集起点与覆盖 |

关于页和404沿用现状。完善既有方法页，不扩写文章或金额页。无公共统计看板，无新登录系统。

## Voice and Tone

表述具体边界：「全年预扣个税」「估算实发」「上海参数已核对」「其他城市需手动参数」。示例文案：「当前基数为估算预设，请按单位申报值核对」；「暂无采集数据」；「广告暂未加载」。不以「最准」「全国政策实时同步」「低竞争高流量」作无证据承诺。

## Component Patterns

| 组件 | 行为 |
|---|---|
| SearchIntro | 上海场景优先，全国累计预扣工具词次级；首屏说明年度、地区、适用人群与下一步 |
| Calculator | 复用既有校验、清除旧结果、聚焦结果、月份切换和本地CSV；拒绝第三方服务不改变这些能力 |
| PolicyCard | 每条来源可打开，生效期明确；说明缴费基数预设可修改，不把估算默认称官方单位申报值 |
| AdSlot | 仅有效平台、有效广告位且获许可后加载；失败不阻断计算，撤回选择后停止后续广告请求并移除容器 |
| PrivacyChoices | 本轮仅管理广告许可；第一方同源无标识PV在隐私页披露，不复用广告选择作为开关；存储不可用时当前页拒绝和撤回仍生效 |
| ReportEntry | 经现有云助手取回汇总，打开本地HTML/JSON；标预览环境、上海时区、生成时间、采集起点、覆盖和首日不完整，不报告UV/真人数 |

## State Patterns

| 表面/状态 | 处理 |
|---|---|
| 页面冷启动/无JS | 静态说明可读，title/H1可见；交互工具需要JS但不依赖第三方加载 |
| 工具空值/输入错误 | 原地提示并关联字段，保留输入、聚焦可修复问题 |
| 工具计算成功/输入变化 | 成功聚焦结果；输入变更清除过期结果，提示重算 |
| 上海政策 | 显示上下半年生效期；未知项标明推断或由单位确认 |
| 方法/政策/隐私 | 静态正文冷启动可读；来源失效不编造新政策，给可追溯名称及日期 |
| 选择未决/已拒绝 | 未决按实际启用项询问；拒绝项不加载对应脚本，功能继续 |
| 选择已允许/重新打开 | 只启用已允许服务；面板反映当前值，修改即时生效 |
| 广告未配置/无填充/错误 | 未配置不显示；无填充或失败安静结束，避免大块永久空白 |
| 统计未配置/空数据/受阻 | 明确无数据与覆盖不足；工具正常，不补造历史 |
| 报告取回无权限 | 明确汇总取回失败，不伪造报告；日志、报告不进公开目录，不嵌入凭据 |
| 离线/第三方故障 | 已加载页面的本地工资计算与本地CSV继续；外链暂不可达不遮挡结果 |
| 键盘焦点 | 可见焦点，阅读顺序与Tab顺序一致 |

## Interaction Primitives

标准链接跳转和按钮操作；表单可键盘提交；同意选项可用Tab、空格/Enter操作。不存在悬停才能发现的关键动作。结果表格使用现有独立滚动区域，整页不因广告或来源URL横向溢出。

## Accessibility Floor

新内容目标WCAG AA，视觉组合见DESIGN.md。所有输入保留label，错误使用aria-describedby/aria-invalid；结果切换和重算提示可被读屏发现。表格保留caption、列/行表头及可聚焦的横滚容器。新交互触摸目标以44px为设计目标；布局兼容200%缩放和360px宽度。图表不得替代文本明细；广告标识无需靠颜色理解。

## Responsive & Platform

继承现有750px和550px断点，新增内容卡在750px以下单列。550px以下采用 DESIGN.md 的 {spacing.mobile-gutter}，导航自然换行；隐私操作在深色面板内纵向排列。上海页首屏说明紧凑，不增加影响首次计算的视觉区块。浏览器验证以用户指定Chrome为主，设计本身不依赖Chrome专属API。

## Key Flows

下述人物仅作验收场景标识，不是经用户研究确认的人群画像。

### Flow 1 — 上海7月调基核对（小周，上海缴费明细变化）

1. 小周从上海搜索词进入上海页。
2. 页面说明上下半年政策与估算预设，默认地区上海。
3. 小周核对缴费基数和公积金档位，必要时填写7月新基数。
4. **关键时刻：** 结果能逐月解释6月与7月差异，并打开对应官方来源。

失败路径：单位申报值不明时提示查工资条或单位记录，不把月工资联动值当作已验证申报值。

### Flow 2 — 逐月个税核对（小林，工资金额相同但月税变化）

1. 小林搜索「工资一样为什么每个月个税不一样」，进入方法页。
2. 看见累计预扣与跨档解释，点击工资计算器。
3. 输入工资与单位申报参数，计算全年。
4. **关键时刻：** 对比不同月份的预扣税和累计应税所得，能把变化与公式对应。
5. 如需保存，下载本地CSV。

失败路径：输入错误保留输入并提示修复；工资与真实工资条不符时能找到适用边界和政策链接。

### Flow 3 — 服务选择（小林，希望只计算工资）

1. 当前无获批联盟代码，广告关闭；未来广告启用时显示PrivacyChoices。
2. 小林拒绝广告；第一方无标识PV在隐私页独立说明。
3. **关键时刻：** 工资计算和CSV照常可用，未获允许的脚本不请求。
4. 从页脚重新打开选择可以更改。

失败路径：浏览器存储不可用时仍可作本页选择；不能因无法持久化而默认同意。

### Flow 4 — 查看浏览量（站长，核对发布后的访问）

1. 站长经现有云助手取回PV汇总，打开本地HTML/JSON ReportEntry。
2. 选择今日、近7天或近30天，看到预览环境、上海时区、生成时间与采集起点。
3. 发起两页受控预览访问，再取回页面路径报告。
4. **关键时刻：** 真实PV出现，并注明覆盖、部分日及不代表真人数。

失败路径：无数据时检查配置、请求拦截、成功GET日志和覆盖区间；不得补造历史或用本地计数填补。

## Measurement Boundary

第一方同源白名单PV：首屏、客户端导航、刷新各上报一次；重渲染不重复，no-store，仅成功GET计数，HEAD、资源和非法路径不计。Nginx专用日志仅时间/页面，不含IP、UA、referrer、query、工资或标识；原始日志保留30天、轮转并限制权限，离线汇总兼容轮转而不重复读取。HTML/JSON报告标预览、Asia/Shanghai、生成时间、采集起点、覆盖与部分日。JS禁用、拦截可漏报，自动化/伪造请求可增加PV；不报告UV、真人数或搜索曝光。本轮不扩展事件追踪。验收检查预览网络请求及真实日志，不以mock替代采集。
