# PayTools 苹果产品页风格重设计

日期：2026-10-24

## 意图

把当前偏绿色、模板感较强的界面重排为接近 Apple 官网的产品页风格：浅灰背景、白色表面、深灰文字、克制的蓝色强调、较大的留白和清晰的内容层级。目标是让用户先理解工具价值，再自然进入计算器，并让结果看起来像可信的产品输出。

## 目标

- 首页首屏更像产品介绍页，突出“输入工资，得到清晰的全年结果”。
- 计算器成为主要白色工作区，减少装饰性绿色块和重阴影。
- 表单、结果汇总、月份明细和政策说明形成明确的视觉层级。
- 移动端保持 360px 可用，首屏仍能看到工资输入和计算按钮。
- 继续使用现有 React 组件、CSS Modules 和静态导出，不新增 UI 依赖。

## 非目标

- 不修改工资计算公式、政策配置、字段名称和校验逻辑。
- 不修改路由、SEO 文案、政策说明内容或广告接入逻辑。
- 不引入 Apple 商标、官方图标或受版权保护的页面素材。

## 方案选择

1. 仅换肤：改颜色、圆角、阴影和字体，风险低，但无法消除首页结构的模板感。
2. **苹果产品页风格重排（本方案）**：保留现有功能和字段，重做首页首屏、计算器容器、结果卡片、导航和移动端节奏。效果与风险平衡最好。
3. 完整组件重构：重新设计表单和结果交互，视觉变化最大，但会扩大行为回归范围。

## 视觉规则

- 页面背景使用接近 `#f5f5f7` 的浅灰，主要面板使用白色。
- 主文字使用近黑灰，次级文字使用中性灰；蓝色只用于主要行动、链接和选中状态。
- 圆角统一为 14–24px，边框使用低对比度灰色，阴影轻而宽。
- 首页使用大标题、短副标题和一张主计算卡；去掉当前绿色信息牌的强烈色块。
- 计算器采用两段式层级：顶部为税前月薪和计算范围，下面为地区、入职月份和可选参数。
- 结果区用四张摘要卡突出全年税前、个人缴费、预扣个税和估算实发；重点值使用深色或蓝色强调。
- 移动端保留适用范围的短提示，不再隐藏全部说明内容。

## 实现边界

- 主要修改 `src/app/globals.css`、`src/components/SalaryCalculator.module.css`，必要时调整 `src/app/page.tsx` 的 class 结构。
- 保留现有语义标签、焦点样式、错误提示、表格滚动和无障碍属性。
- 先运行现有单元/组件测试，再执行静态构建并刷新本地预览；Next.js 当前安全检查阻塞需要单独记录，不通过改 UI 绕过。

## 验收标准

- 首页和计算器页不再以绿色作为主品牌色，整体呈现浅灰/白色/蓝色的克制层级。
- 1440px 桌面视图中，首屏主标题、说明和计算卡具有明显的产品页层级。
- 360px 视图中，税前月薪输入、计算范围和计算按钮可见且无横向溢出。
- 计算结果的金额、表格、错误提示和键盘焦点行为与重设计前一致。
- `npm run lint`、`npm run typecheck`、`npm run test` 通过；静态预览能打开首页和计算器页。
