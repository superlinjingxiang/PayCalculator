# 年度收入构成饼图设计说明

日期：2026-10-24

## 目标

在计算结果的“全年一览”下增加一个可读的年度收入构成图，让用户直接看到税前工资如何分成个人缴费、预扣个税和估算实发，并把个人缴费继续拆成养老、医疗、失业和公积金。

## 选择

使用 React + SVG 实现，不新增图表依赖。SVG 圆环按年度结果实时计算，旁边提供带金额和占比的文字图例；图例是无障碍和移动端的主要信息来源。

## 口径

- 总额使用 `result.grossTotal`。
- 个人缴费使用每月 `contributionsByType` 汇总，拆成养老、医疗、失业、公积金。
- 预扣个税使用 `result.taxWithheldTotal`。
- 估算实发使用 `result.takeHomeTotal`。
- “仅算个税”模式的个人缴费各项显示为 0，并明确说明该模式未扣五险一金。
- 总额为 0 时显示空圆环和 0.0%，不出现 NaN 或错误比例。

## 视觉与交互

- 使用当前苹果风格的蓝色、紫色、橙色、青色和中性灰，避免恢复绿色品牌色。
- 图表和图例放在全年摘要卡片之后、单月摘要之前。
- SVG 使用 `role="img"` 和可读的 `aria-label`；完整金额和占比在图例中可见。
- 不修改计算公式、输入字段、模式默认值或结果表格。
- 移动端图表和图例纵向排列，禁止横向溢出。

## 验收标准

- 详细模式下四项个人缴费可分别看到金额和占比，且合计与全年个人缴费一致。
- 预扣个税和估算实发可看到金额和占比，所有占比合计约 100%。
- 仅算个税模式明确显示五险一金为 0，并保持现有提示。
- 现有计算和表格测试继续通过。
- 新增组件测试覆盖详细模式、仅算个税模式和零总额边界。
