# 信息流广告接入准备

更新日期：2026-10-27

## 当前状态

代码已经具备广告开关、用户同意门禁、结果页广告位和正文后广告位，但**没有加载任何第三方广告 SDK**。默认配置下不会渲染广告容器、不会显示同意横幅，也不会发起广告网络请求。

目前无正式域名、适用备案材料及获批联盟账号，本轮仅修复同意状态与交付申请清单，真实广告接入和平台投放验收仍未完成。不得把空容器、开关或模拟slot当作接入证明。

## 申请顺序与材料

依据[本轮调研](../_bmad-output/growth-2026-10-27/research/research.md)，优先询证百度联盟网站业务，360媒体联盟备选。百度[历史帮助](https://so.baidu.com/wiki/help/3478.html)及旧网站合作指南不能证明2026新站准入；360[当前申请表](https://lianmeng.360.cn/index/signup)收集域名验证、备案、访问量及主体财务信息，填表不等于获批展示广告。没有核实最低PV、审核时长或收益，不以网上数字作为保证。

- 准备可验证正式域名、HTTPS、适用备案和主体/收款资料；不擅自购买域名或签协议。
- 向百度网站业务确认接受普通静态PC/WAP工资工具、个人/企业主体条件、备案要求、真实流量材料与内容审核要求。
- 若不适用，向360确认本账号有Web展示广告权限（导航联盟权限不等于媒体展示）、域名验证、备案、结算与类目限制。
- 审核通过后保存实际Web代码、官方接入文档、广告位ID、域名白名单和广告规格；仅依获批代码实现适配，不猜测SDK接口。
- 正式HTTPS域名、所需资质及真实平台响应、明确广告标识、拒绝无请求、撤回与失败恢复、适配器不读表单等全部验收后再激活。真实广告仍是待办，增长总目标不可标为完成。

当前广告位：

- `result-footer`：完成工资计算后，显示在结果区域下方。
- `content-footer`：首页和工资计算器说明内容之后。

广告位不复用表单数据。`AdSlot` 只接收广告位名称，不接收工资、地区、缴费基数、扣除金额或计算结果。

## 构建配置

广告配置会在 `next build` 时写入静态文件，修改后必须重新构建：

```dotenv
NEXT_PUBLIC_ADS_ENABLED=false
NEXT_PUBLIC_AD_PROVIDER=
NEXT_PUBLIC_AD_RESULT_SLOT=
NEXT_PUBLIC_AD_CONTENT_SLOT=
```

这些 `NEXT_PUBLIC_*` 值会进入浏览器代码，不能放密钥、访问令牌或平台账号密码。

即使把 `NEXT_PUBLIC_ADS_ENABLED` 设为 `true`，缺少 provider 或对应广告位 ID 时也不会渲染广告容器。当前版本还没有具体平台的脚本加载器，因此广告位会保持空白，不能把“打开开关”当作完成投放接入。

## 同意行为

- 未选择时，仅在广告功能启用后显示广告设置。
- 选择“仅用必要功能”后，不加载广告容器；计算和 CSV 下载不受影响。
- 选择“同意展示广告”后，才渲染带 `data-ad-*` 属性的广告容器。
- 选择保存在浏览器 `localStorage`，键名为 `paytools-ad-consent-v1`。
- 页脚“广告设置”可以重新打开选择；拒绝或同意会立即同步到当前页面。
- localStorage读取或写入被拒时，当前页面使用内存选择；拒绝、撤回和其他标签页的变更立即同步。刷新后不能持久化时重新询问。
- 广告位必须显示“广告”标识，并与计算按钮、结果数字清楚区分。

## 平台接入前仍需完成

1. 确定已获批的广告平台、发布商账号、广告位 ID、素材规格和计费方式。
2. 在 `src/components/AdSlot.tsx` 中实现具体平台的脚本加载和初始化逻辑，并继续以用户同意为前置条件。
3. 更新隐私说明，写明平台名称、运营主体、Cookie 或设备标识、数据类型、用途、保存期限和退出方式。
4. 如果平台要求，增加并核验 `ads.txt`、站点验证文件或域名验证记录。
5. 按平台要求配置 CSP、`connect-src`、`script-src`、`frame-src` 和图片域名白名单；不要使用无限制的 `*` 允许列表。
6. 禁止向广告请求传入工资、缴费基数、扣除金额、CSV 内容、自由文本或能反推出个人薪资的事件参数。
7. 对广告内容做人工审核，避免税务、贷款、投资等误导性承诺；不得伪装成计算结果或政策提示。
8. 在 360px 手机、常见桌面宽度、慢网和断网状态下检查广告不遮挡输入、结果、政策来源和下载按钮。
9. 正式开启前用浏览器网络面板确认：未同意时没有广告域名请求；同意后才出现预期请求；请求参数不含工资字段。
10. 记录平台审批截图、广告位配置、隐私版本和上线回滚方式。

## 广告位接入契约

同意后渲染的容器包含：

```html
<aside aria-label="广告">
  <span>广告</span>
  <div
    id="paytools-ad-result-footer"
    data-ad-provider="provider-name"
    data-ad-slot="provider-slot-id"
    data-ad-format="fluid"
  ></div>
</aside>
```

具体平台适配器应只读取上述容器属性，不读取 React 表单状态。广告加载失败时应保持页面布局稳定，不阻断计算和 CSV 下载。

本站只承诺不主动向广告请求传入工资字段。平台脚本有页面执行能力，应审核其真实行为后披露，不能未经审计就声称第三方永远无法读取页面内容。撤回需移除广告、停止后续请求并执行平台支持的清理；已执行脚本的控制边界须在获批适配阶段验收。

## 推广活动与站内广告的边界

如果“信息流广告”指的是购买投放来推广本站，应另外准备落地页、素材、UTM 参数和转化事件。UTM 只记录页面或渠道，不得写入薪资金额。建议的匿名事件只有：

- `calculator_started`
- `calculation_completed`
- `policy_sources_opened`
- `csv_downloaded`

事件参数仅允许页面路径、广告位或活动名称，不允许金额、地区明细、扣除项目或个人标识。
