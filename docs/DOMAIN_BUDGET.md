## 适配现有大陆 ECS 的实际条件

- **可以个人注册并准备个人网站备案，但必须按真实用途审核。** 阿里云个人网站流程支持个人主体；域名需实名认证。域名持有人名称、证件类型和号码需与个人备案主办者一致；后缀和注册商均应在工信部批复范围，不能仅凭注册成功判断可备案。[个人网站流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)、[域名核验要求](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/prepare-and-check-the-domain-name)
- **上海属于可备案大陆地域，优先使用现有实例。** 官方 ECS 条件包括包年包月（含自动续费三个月及以上）及公网 IP。主任务2026-10-29通过现有凭证只读核对：当前ECS为包年包月、2核2GiB、有公网IPv4，2026-09-05创建、2027-09-05到期，初步满足时长和公网条件；仍需在备案控制台确认可选实例、主体及免费名额，不等于已获备案批准。不要为一个域名先买第二台机器或付费服务码。[ECS备案条件](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)、[服务码及免费名额](https://help.aliyun.com/zh/icp-filing/basic-icp-service/support/server-check-faq)
- **腾讯云买域名不要求搬迁现有阿里云服务器。** 阿里云流程明确允许非阿里云注册域名，需等待域名信息入库后申报；仍由服务器接入商阿里云办理备案。选择阿里云注册可减少这一步的等待，但不保证审批通过。[个人网站流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)
- **基础备案服务不收费，增值代办收费。** 不需要因备案本身购买管家；上线前完成ICP备案，网站开通后按要求在30日内办理公安联网备案，并按审核结果展示/链接备案信息，具体以主管机关要求为准。主体所在地、网站内容、名称以及管局要求尚未确认，不能预先承诺具体审批结果或完成日期。[备案计费](https://help.aliyun.com/zh/icp-filing/product-overview/product-billing)、[备案流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)、[个人网站时序](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)

`.top/.xyz` 在这里仅用于成本对照；本轮未逐项核实其具体注册商当前批复及可备案状态。选择 `.cn` 也仍须核对实际注册主体、普通词价格及备案核验，后缀不替代审核。

## 免费 DNS 与 HTTPS 可用，注意续期和服务边界

**DNSPod 免费权威 DNS 是合适的低成本起点。** 腾讯云 2026-07-20 版本对比明确把免费版适用站点列为“个人网站或服务”，支持 A/CNAME/TXT 等基本记录和 API，但没有可用性等级、免费版无安全防护；这不等于必须买付费 DNS。对当前小流量、单 ECS 工具站，可用免费版并接受故障边界，保留记录备份及迁移能力。腾讯云/DNSPod 账号需实名认证，NS 地址以账号控制台实际分配为准，不能照抄网上旧地址。[版本对比](https://cloud.tencent.com/document/product/302/106264)、[实名要求](https://cloud.tencent.com/document/product/302/103747)、[NS地址说明](https://cloud.tencent.com/document/product/302/79833)

阿里云也有免费权威解析；但 2026-09-17 的官方免责声明将免费服务定位为测试或非关键用途，并**不建议**用于正式对外生产服务，且无 SLA。这里是官方不推荐及服务保障边界，**不是本轮证据证明的绝对禁止，也不推出必须付费**。为了减少与该定位的冲突，本项目优先 DNSPod 免费版，而非增加预算买阿里云付费解析。[阿里云免费DNS条款](https://help.aliyun.com/zh/dns/free-service-disclaimer)

**Let's Encrypt 证书本身免费，可用 ACME 客户端自动申请与续期。** 官方推荐 Certbot；现有 Nginx/ECS 可作为实施路径，但尚未配置验证。须能证明域名控制权：HTTP-01 要求公网 80 端口可达，DNS-01 通过 TXT 记录验证。备案、DNS解析、安全组/防火墙和 Nginx 配置满足后再部署，保留自动续期、续期失败提醒和到期检查。[Let's Encrypt介绍](https://letsencrypt.org/about/)、[接入指南](https://letsencrypt.org/getting-started/)、[验证方式](https://letsencrypt.org/docs/challenge-types/)

不需要先购买付费 SSL/通配符证书。阿里云也提供每实名主体每自然年最多20张、每张90天的免费“个人测试证书”，官方用途是开发测试；不把人工反复换测试证书当成本项目正式 HTTPS 的首选。[阿里云测试证书](https://help.aliyun.com/zh/ssl-certificate/purchase-an-individual-test-certificate)

在上述条件成立、沿用现有合格 ECS 时，**三年新增域名 + 免费 DNS + 免费证书 + 自助基础备案，按当前常规 `.cn` 报价预算约 115–123 元，建议预留上限 150 元**。这是域名相关增量现金预算，不含服务器、人工或广告平台可能要求的资质成本；后两项尚未确定，不能以广告收入作抵扣保证。

## 个人工具站与广告联盟：购买前先厘清主体

“免费工资估算工具能备案”与“个人备案可直接放联盟广告赚钱”是两个审核问题。现行《互联网信息服务管理办法》区分有偿与无偿信息服务，分别实行许可和备案制度，并要求按核准/备案项目提供服务；本轮未取得“本工具采用某种联盟广告模式可作为个人主体经营”的主管部门结论。[司法部现行法规](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=1756)

阿里云目前建站备案指引把广告列作经营性业务示例，并说明个人主体不可用于商业用途；其备案核查说明也列出“内容与主体不符”“涉及经营性”为整改原因。这是应在实际方案中解决的接入审核限制，不能简单承诺“个人备案肯定可投”，也不能仅凭该指引断言一切免费站广告情形都必须购办某种许可证。[阿里云建站备案指引](https://help.aliyun.com/zh/document_detail/3043304.html)、[备案核查说明](https://help.aliyun.com/zh/icp-filing/basic-icp-service/for-the-record-information-special-verification-faq)

360 当前申请页面提供个人/企业财务对象，要求域名验证、网站访问量、备案信息；这只证明表单有个人收款路径，**不证明个人备案工具站已获准Web广告业务，也不保证百度或360接收本项目**。[360申请页](https://lianmeng.360.cn/index/signup)

实际广告激活前，应向接入商/主体所在地管局确认“个人、免费工资工具、拟展示具体联盟广告”的备案/许可适用性，再向联盟确认主体、工具类内容、备案与结算要求，并取得审核结果。若不接受个人主体，应先评估是否值得继续广告变现；不要为了未知的小额收益盲目注册公司、买更多服务器或代办套餐。域名后缀本身不保证广告准入、收益、流量或搜索排名。
